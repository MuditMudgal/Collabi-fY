# Collabify

A real-time collaborative code editor that allows multiple users to join the same room and write code together in real time.

## Features

- Real-time collaborative code editing
- Multiple users can work in the same room
- Unique room ID generation
- Join rooms using a room ID
- Live connected-user list
- Real-time code synchronization using Socket.IO
- Syntax highlighting with CodeMirror
- Copy room ID functionality
- Simple and responsive interface

## Tech Stack

- React.js
- Node.js
- Express.js
- Socket.IO
- CodeMirror
- JavaScript
- CSS

## How It Works

1. Create a new room or enter an existing room ID.
2. Enter your username.
3. Share the room ID with other users.
4. Everyone joining the same room can edit the code together.
5. Code changes are synchronized in real time using Socket.IO.
